# Sitzplan-Manager

Interaktive Web-App zur Erstellung von Sitzplänen und zur Unterrichtsdokumentation.

## App öffnen

**[Sitzplan-Manager starten](https://mueller-sh.github.io/sitzplan/)**

Direktlink: https://mueller-sh.github.io/sitzplan/

Die App wird über GitHub Pages aus der Datei `index.html` bereitgestellt.

## Entwicklung

- **iPad:** Änderungen im GitHub-Repository `mueller-sh/sitzplan`, Test in Safari über GitHub Pages.
- **Mac:** Lokal an der HTML-Datei entwickeln und testen, danach Änderungen nach GitHub übertragen.
- **Notion:** Anforderungen, Roadmap, Entscheidungen und Testergebnisse im Projekt „Sitzplan-Manager – Interaktive Unterrichts-Web-App“ dokumentieren.

## Hinweis

Die App befindet sich in der Prototypenphase. Bitte zunächst mit Beispieldaten testen. Keine personenbezogenen Schülerdaten im öffentlichen GitHub-Repository speichern.
